# Resetting a User Password in Active Directory

## Overview
This guide provides step-by-step instructions for resetting a user's password in Active Directory.

## Steps

### 1. Access User Management
Access the user management section in Active Directory.

### 2. Search for the User
Search for the user whose password needs to be reset (e.g., 'Bob Rich') and select the user from the list.

### 3. Open Reset Password Option
Right-click on the selected user and choose 'Reset Password' option from the menu.

### 4. Enter New Password
Enter a new secure password for the user ensuring it meets security requirements.

### 5. Confirm and Notify
A confirmation message will indicate that the password has been changed and you can now notify your user they can log in with new password.

## Security Requirements
- Ensure the new password meets your organization's security policy
- Use a combination of uppercase, lowercase, numbers, and special characters
- Avoid common words or easily guessable patterns

## Notes
- The user will typically be required to change their password on first login
- Document the password reset in your ticketing system if applicable
